# Application Blueprint

## Primary Positioning

Use this headline for most applications:

> Robot Learning / Embodied AI Research Engineer focused on humanoid reinforcement learning, sim-to-real transfer, imitation learning, and real hardware deployment.

Use this when applying to more abstract RL / general intelligence roles:

> Reinforcement Learning Research Engineer interested in scalable RL systems, recurrent state estimation, planning, embodied agents, and general physical intelligence.

## Portfolio Link Strategy

The resume should link to:

- GitHub: code and repositories
- Portfolio: videos and demonstrations
- LinkedIn: recruiter workflow

The website should link back to:

- current resume PDF
- GitHub
- LinkedIn
- email

The resume should not describe every video. Use one line such as:

> Hardware demos and project videos: https://moritzschwerer.github.io

## Tailoring Rules

For each application:

1. Copy the base resume.
2. Rename it for the company, for example `moritz-schwerer-neura-rl-humanoid.pdf`.
3. Reorder project bullets so the first 5 bullets match the job ad.
4. Replace generic phrases with the exact true terms from the posting.
5. Keep the resume one page unless the role explicitly asks for a full academic CV.

## Cover Note Template

Subject: Robot learning / sim-to-real candidate for [Role]

Hi [Name],

I am applying for [Role] because it matches the work I have been doing in humanoid robot learning: recurrent RL trained in simulation, transferred to real hardware, and evaluated through onboard robot behavior rather than only offline metrics.

My main project is an autonomous Booster T1 soccer controller that searches for the ball, approaches, aligns, kicks, resets, and continues in one onboard policy using camera-based perception and odometry. I also built motion-imitation tooling for Unitree G1 from AMASS / SMPL-H data and worked on deployment/runtime optimization using ONNX Runtime and robot SDK interfaces.

The demos are here: https://moritzschwerer.github.io

Best,
Moritz

## Before Applying

- Confirm education dates and whether to include grade/GPA.
- Decide whether to include grade/GPA. Include it only if it helps.
- Add thesis supervisor / lab if recognizable and appropriate.
- Add direct project GitHub links if the repositories are public and clean.
- Make sure every claim on the resume can be defended in an interview.
- Build the PDF and test all links.
